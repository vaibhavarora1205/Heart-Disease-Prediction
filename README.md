# Heart Disease Prediction

A machine learning project built as part of my journey to learn **Supervised Learning** using Python and Scikit-learn.

The project uses a trained classification model to predict heart disease risk based on user-provided health parameters. I also built an interactive web interface using Streamlit to understand how a machine learning model can be integrated into a web application.

## What I Learned

- Understanding supervised learning and classification
- Working with health-related datasets using Pandas and NumPy
- Data preprocessing and feature scaling
- Training and using a machine learning classification model
- Saving and loading trained models
- Building an interactive ML application with Streamlit

## Tech Stack

- Python
- Pandas & NumPy
- Scikit-learn
- Streamlit
- Joblib

## Features

- Interactive input fields for health parameters
- Heart disease risk prediction using a trained model
- Integration of a saved model and preprocessing components
- Real-time prediction results

## Live Demo

[Try the Live App](https://heart-disease-perediction.streamlit.app/)

## Disclaimer

This project was developed for educational purposes while learning supervised machine learning. Its predictions are not a medical diagnosis and should not be used for medical decision-making.
